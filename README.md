# SJ-1测试版 · FlatCircle 扁平社交圈

一个零构建的 Vue 3 单页社交演示应用：账号体系、信息流、好友、私信与通知一应俱全。双击 `index.html` 即可运行，无需 Node、无需打包、无任何外部网络依赖。

## 功能

- **账号体系**：注册 / 登录 / 退出；每个账号拥有独立的数据快照（帖子、好友、私信互不干扰）。内置演示账号 `@aze`，密码 `123456`。
- **信息流**：发帖（文字 + 标签）、点赞、评论、关注、按标签筛选。
- **好友系统**：发送好友申请，接受 / 忽略收到的申请，撤回发出的申请，删除好友；机器人账号会在片刻后自动接受申请并发送问候私信。
- **私信与通知**：一对一会话；通知中心汇总点赞、评论、关注、好友申请等消息。
- **探索与个人主页**：发现推荐账号、浏览他人主页、编辑自己的资料（昵称 / 简介 / 头像等）。
- **主题**：浅色 / 深色一键切换，偏好本地记忆。

## 运行方式

直接双击 `index.html` 即可（基于 `file://` 协议运行，无需任何服务）。

如需通过本地服务器访问：

```bash
python -m http.server 8000
# 然后打开 http://localhost:8000
```

## 技术要点

- **零构建**：Vue 3 全局构建版（`js/vendor/vue.global.js`）本地内置，全部使用传统 `<script>` 标签按顺序加载，不依赖 CDN、不发起任何网络请求，完全离线可用。
- **组件注册**：各视图 / 组件以普通对象形式挂在 `window.FC` 上，由 `app.js` 统一 `app.component(name, component)` 注册。
- **状态管理**：基于 `Vue.reactive` 的单例 store，配合防抖写入 `localStorage` 持久化。
- **数据隔离**：按账号维度存储——
  - `flatcircle:accounts:v1`：账号表
  - `flatcircle:session:v1`：当前会话
  - `flatcircle:data:v1:<账号ID>`：每个账号独立的世界快照
  - 旧版 `flatcircle:data:v1` 数据首次启动时自动迁移到演示账号 `@aze`
- **设计风格**：扁平化设计，无阴影、无渐变；颜色全部取自统一的 CSS 变量（`--primary` / `--ok` / `--warn` / `--like` 系列及 `--r-*` / `--t-*` 圆角与排版变量）。

## 目录结构

```
index.html             入口页面与脚本加载顺序
css/styles.css         全部样式（含主题变量与各视图样式）
js/
  vendor/vue.global.js Vue 3 全局构建版（本地内置）
  utils.js             工具函数
  data.js              种子数据
  icons.js             图标组件
  store.js             全局状态与持久化
  ui.js                通用 UI 组件
  feed.js              信息流视图
  social.js            账号 / 好友 / 私信等社交视图
  app.js               应用装配与组件注册
```
